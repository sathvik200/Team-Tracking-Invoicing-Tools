Two Excel tools based on systems I built and use at work:



* Automated Invoicing System: turns daily hour logs into a client-ready invoice, separating Test and Lead hours by role. It cut month-end invoicing from 3–5 days to a ready-to-send invoice on day one.



* Bug Tracker \& Performance Dashboard: testers log bugs daily, scores are calculated automatically, and PivotCharts show the top performers in each category for quarterly reviews. New testers are picked up without rebuilding the dashboard.



All data in this repository is sample data.
